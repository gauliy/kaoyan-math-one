# 训练与复盘

## 选择任务与安排复测

先看到期项与近期重复卡点，选择少量任务；用户时间未知时先给短组，允许调整。原题重做检验关键步骤，同类变式检验迁移，条件变化检验适用边界，混合题检验自主识别方法。重复训练失败时先查前置能力，不单纯增加同类题数量。

自编题须保存自编标记、已验算解法与答案。标准答案单独保存于记录，面向用户只展示题目，用户提交或索要后再给。不能把换数字但逻辑没有变化的练习作为强迁移证据。来源无法核实时标“来源待确认”，不能称某年真题。

默认首次检查可次日，随后约3–7天、1–2周；仅作为选项，具体日期由学习情况、任务量和用户时间决定。安排日期按档案时区生成；错过的复测继续待办，不能算作失败或未掌握。历史迁移首次复测安排在导入后，不倒推虚构结果。

提交复测后：追加新的作答，记录原题/变式/混合、提示量、是否见过答案、方法选择与错误；更新关联薄弱点；将该复测标为已完成并保存结果，有需要再创建下一次安排。一次偶然笔误与方法性失败分开。

## 状态更新依据

| 掌握状态 | 必须具有的证据 |
| --- | --- |
| 待检查 | 无可靠独立表现，或仅看过解析 |
| 需要提示 | 实际作答需要提示才能推进 |
| 能独立完成 | 无提示、未先看答案的完整作答 |
| 间隔后仍能完成 | 不同日期、经过间隔的独立完成；保留日期与题目依据 |
| 能迁移到变式 | 有实质变化的题目独立完成；区分紧接讲解的近迁移与间隔复测 |

以上是可解释状态，不是精确评分。某题的学习状态是另一个维度；“已讲解”不是上述掌握等级。升级需要证据；失败后可调整状态并说明原因，同时保留之前成功记录。用户自述“懂了”记为自述理解，可安排检查，不能冒充测试结果。

## 每日复盘

按用户本地日期筛选“作答”的日期，不按数据库写入日期判断今日学习。汇总已处理题目、涉及知识、已表现能力、主要卡点、短经验卡、2–3个回忆问题、到期项和下一次1–2件优先任务。没有今天作答时说明，能提供历史待复测清单；不能把导入旧题说成今日新学。

不附全部长解析，不凭答对率估算分数。保存 summary 记录，类型为每日，日期与覆盖范围明确。用户当天再次复盘时更新该日记录的新版本，保留旧版。

## 阶段总结

“本周”按本地周一至周日；用户指定范围优先。依据作答与复测比较：改善及证据、反复卡点、只看懂未验证、前置知识、下一阶段优先任务；如用户请求可附短训练组且暂不揭答案。已有旧记录但无近期作答时不要声称取得近期进步。

数量不能替代掌握证据，建议具体到内容与动作，例如“先练画积分区域，再做交换积分次序”，不要笼统“加强高数”。学习累积明显且用户处于学习对话时可提示适合复盘，但不要每题都提醒。总结依赖对话触发，后台提醒另行配置。
